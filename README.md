# 독서동호회 희망도서 신청

독서동호회 회원들이 읽고 싶은 책을 신청하고, 신청 현황과 남은 지원금을 확인할 수 있는 웹 서비스입니다.

## 왜 만들었나

동호회는 정기적으로 회원들에게 희망도서를 신청받습니다. 그동안은 메시지나 메일로 받은 신청을 운영자가 일일이 정리하고, 각자 지원금을 얼마나 썼는지 따로 계산해야 했습니다. 이 서비스는 그 과정을 하나의 화면으로 모아, 회원은 간단히 신청하고 운영자는 바로 현황을 볼 수 있게 합니다.

## 주요 기능

### 도서 신청
회원이 소속과 이름을 고르고 도서명·출판사·가격(선택으로 구매 링크)을 입력해 신청합니다.
- 신청은 현재 진행 중인 회차에 자동으로 기록됩니다.
- 명부에 없는 소속·이름 조합은 접수되지 않습니다.
- 지금까지 신청한 책값의 합이 본인 지원금을 넘으면 신청할 수 없습니다. 신청이 완료되면 남은 지원금을 바로 알려줍니다.

### 신청 도서 조회
회원이 소속과 이름을 선택하면, 지금까지 모든 회차에 걸쳐 본인이 신청한 도서 목록을 볼 수 있습니다.
- 도서, 출판사, 가격, 회차, 구매 링크를 한눈에 확인합니다.
- 목록 아래에 사용한 금액 합계와 남은 지원금이 표시됩니다.

### 관리자 페이지
운영자 전용 공간으로, 비밀번호를 입력해야 들어갈 수 있습니다.

**회원 관리**
- 전체 회원을 소속, 이름, 위치로 걸러 볼 수 있습니다.
- 회원을 새로 추가하거나, 정보를 수정하거나, 명부에서 삭제할 수 있습니다.
- 회원의 이름이나 소속을 바꾸면 그 회원의 기존 신청 내역에도 같이 반영됩니다.

**신청도서 관리**
- 모든 회원의 신청 내역을 한 화면에서 봅니다. 각 신청에 신청자의 위치와 현재 남은 지원금이 함께 표시됩니다.
- 소속, 이름, 위치, 회차, 단계, 도서명·출판사로 자유롭게 필터링하고, 걸러진 결과의 건수와 금액 합계를 확인합니다.
- 필터링한 결과를 그대로 PDF로 저장할 수 있습니다. 출력일시와 적용한 조건이 함께 인쇄됩니다.

## 사용 흐름

1. 회원은 안내받은 주소에 접속해 **도서 신청** 메뉴에서 책을 신청합니다.
2. 궁금할 때 **신청 도서 조회**에서 본인의 신청 이력과 잔액을 확인합니다.
3. 운영자는 **관리자 페이지**에서 회원 명부를 관리하고, 회차가 끝나면 신청 내역을 모아 PDF로 정리합니다.

## 데이터 관리

모든 신청 내역과 회원 명부는 운영자의 구글 스프레드시트에 저장됩니다. 운영자는 스프레드시트에서 직접 내용을 확인하거나, 현재 회차를 바꾸거나, 신청 상태(단계)를 갱신할 수 있습니다. 회원에게는 스프레드시트가 노출되지 않습니다.
